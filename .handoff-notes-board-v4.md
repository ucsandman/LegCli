# Handoff Notes: baton board and marketing site on the v4 dark product direction

## Scope

A long session that shipped one real commit to baton (`ddf3ca2`: board redesign, folder-trust records, two scroll fixes, docs, demo assets) and then spent six rejected rounds trying to make the board UI look good. The cause of the rejections was finally identified: every attempt was built against `DESIGN.md`'s "printed hardware manual" brief, which is the opposite of the consumer-product finish the operator asked for. A fresh round of three mocks, built by agents that actually loaded the design skills, produced a direction the operator accepted: mock B, "dark product surface". The session paused before porting B into `src/board/`, at the operator's request, to continue in a new session with a smaller context.

## Projects Mentioned

- baton — the npm package `baton-agents`, a local CLI that wraps coding agents and serves a board on 127.0.0.1
- baton board — the product UI at `src/board/` (`/` and `/floor`)
- baton marketing site — `site/`, deployed to baton-agents.vercel.app
- context-handoff-bundle — the handoff tool baton itself depends on
- ui-ux-pro-max — a Claude Code plugin installed this session while searching for design tooling

## Findings

- The agreed direction is `.design/board-v4/b-dark-product.html`, mock B, with two grafts: mock C's headline framing ("All four terminals are on claude, and claude has 5% left") replacing B's hero, which restates its own number, and mock A's staleness sentence ("Measured 2h 13m ago. Four terminals have been running since, so the real figure is higher than 95 percent, never lower").
- Six earlier designs were rejected because they were all built against `DESIGN.md`, whose brief is "exact, unhurried, mechanical, the printed operator's manual for a piece of test equipment" with a sharp radius stance of "2px on controls, 3px on plates, never 8px" and "no cards as layout". That brief cannot produce what the operator asked for and `DESIGN.md` must be rewritten to match B.
- The v3 mocks failed for a second, independent reason: the subagents that built them never loaded the design skills and worked from a paraphrase in the prompt. The v4 agents invoked `frontend-design:frontend-design` and `impeccable:impeccable` via the Skill tool and ran three self-critique rounds against their own screenshots. Design agents must be spawned as `general-purpose`; the lean agent types have no Skill tool.
- The single most expensive process mistake was measuring the redesign against a board of healthy terminals. The compact styling was scoped to `.panel.is-running`, which reported 40px rows, while the operator's real board is mostly `lost` and `ended` terminals and showed 400px rows. Any future board work must be verified against a board seeded to look like the operator's.
- Six information-design changes in the uncommitted `src/board/sessions.js` survive any visual direction and are worth keeping: `promptText()` stripping image tags, `fileLabel()` printing basenames, the finished-terminal collapse, `sharedNotes()`/`hoistShared()`, the honest region count, and the commit log collapsing to the last three.
- `site/` has 845 uncommitted lines that rebuilt its DOM board recreations to depict the rejected board. The recreations and their copy are stale and must be rebuilt against B. The accessibility floor fix inside that change (text below 14px at <=560px) is independent and worth keeping.
- Baton's own board on port 4747 carries the operator's real coding sessions. All verification must use an isolated port and a throwaway `BATON_HOME` with `BATON_TRUST=never`.
- `ddf3ca2` shipped a genuine bug fix that predates the redesign: `sessions.js` guarded both usage bars with `!walled &&`, so hitting a usage limit hid the two numbers that explain the limit.
- `ddf3ca2` also shipped folder-trust records so a handoff does not stall on an agent's first-run trust prompt. An earlier version of that code silently reversed a user's recorded "no"; only an absent key now counts as an unanswered question.
- Two scroll defects were found and fixed after the operator reported them: `putFocus()` called `focus()` without `preventScroll` on a 3-second rebuild, pinning the viewport to whatever button had been clicked; and re-parenting the expanded detail region zeroed `scrollTop` inside an open diff.
- A web search for design tooling was largely a dead end. The top-recommended plugin, `ui-ux-pro-max`, is brand, logo, banner and slide material whose on-disk data is `slide-layouts.csv`, `logo/` and `icon/`. Anthropic's own `frontend-design` was the useful one.
- The marketing site's OG card advertised a commercially licensed product as MIT. The tag line now names the price, and `.cmd` is pinned to one line so a longer copy string cannot break the layout again.
