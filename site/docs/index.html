Baton documentation

Baton is a local wrapper for coding-agent CLIs: type baton claude, baton codex or baton agy and you get the same interactive agent with a board beside it, usage tracking per agent and account, a handoff bundle kept current, and an automatic handoff to the next agent in the same terminal when the usage limit hits.

The source repository is private. These pages carry the same text as the documentation shipped inside the npm package, so every claim on the site can be checked before you buy, and the source itself is readable at $(npm root -g)/baton-agents/src after you install.
